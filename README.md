# Grocery

A simple grocery management/application project designed to make it easier to organize and manage grocery items.

## 📌 Project Description

**Grocery** is a project focused on managing grocery items in an organized and convenient way. It can be extended with features such as adding products, updating quantities, removing items, and maintaining a grocery list.

## ✨ Features

* Add grocery items
* View grocery items
* Update item details
* Delete grocery items
* Manage grocery lists
* Simple and user-friendly interface
